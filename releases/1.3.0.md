## Privacy Display+ 1.3.0

- Add Off, On and Maximum choices for the visible lock screen. The module's
  request ends at credential entry, ambient display or unlock.
- Add a separate Maximum option for PIN, pattern and password entry. It changes
  the level only while Samsung's own secured-screen condition protects entry.

## Updating

Install the APK over the existing app to keep your settings. Keep **System
Framework** and **System UI** enabled in LSPosed, then soft reboot once to load
the updated hooks. Both new choices default to Off after upgrading.

Samsung's PIN, pattern, password condition must be enabled for its Maximum
option to apply. Maximum remains a shared display level: two protected regions
cannot use On and Maximum independently. The new lock-screen and credential
routes still need off-axis device validation on the supported firmware.
